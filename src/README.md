# Source Scripts

Copy the standalone source files developed in VS Code into this folder.

Minimum contents:
- `Execution.py`
- `Validation.py`

You may also add older development versions, but only if they have genuine documentation value. Working backups should not be included in a public repository.

Tips:
- only include current, well-commented versions in the public release
- if you want to keep old versions, place them in a separate `archive/` subfolder and explain why they are there
