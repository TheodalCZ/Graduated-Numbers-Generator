# Repository Structure Explained

This document explains why files are split across several folders.

## `toolbox/`

Contains the publishable version of the ArcGIS Pro toolbox in `.atbx` format.

## `src/`

Contains standalone source files developed in Visual Studio Code. These files serve as a source, documentation, and development counterpart to the embedded toolbox inside the `.atbx` file.

## `docs/`

Contains the thesis summary, upload guide, and repository structure explanation.

## `examples/`

Contains screenshots, map exports, and other demonstration outputs of the tool.
