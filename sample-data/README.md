# Sample Data

The sample maps included in this repository were created using data sourced from **ArcGIS Online** (via the ArcGIS Portal). Because these datasets are hosted externally and subject to their respective terms of use, they cannot be redistributed here.

## Data sources used in the sample maps

| Provider / Author | Dataset | Coverage | Type |
|---|---|---|---|
| ARCDATA PRAHA, ZÚ, ČSÚ | Kraje (ArcČR 2024) | Czech Republic | Vector (ArcGIS Online) |
| MB Research / Esri Germany | Germany Bundeslander Boundaries | Germany | Vector (ArcGIS Online) |
| Mareike Kortmann | 112 Standorte - Feuer- und Rettungswachen | Germany | Point (ArcGIS Online) |
| GUS / Esri Polska | Population Variables Boundaries [Dane demograficzne] | Poland | Vector (ArcGIS Online) |
| Jennifer Boehnert | country_Europe | Europe | Vector (ArcGIS Online) |
| OurAirports.com | airports.csv | Global | Point (.csv) |

## How to obtain the data

1. Open [ArcGIS Online](https://www.arcgis.com) and search for the dataset by name.
2. Add it to your ArcGIS Pro project as a hosted feature layer.
3. Run the **Graduated Numbers Generator** tool on the loaded layer.

Alternatively, any polygon or point layer with a numeric attribute field can be used to try out the tool.
